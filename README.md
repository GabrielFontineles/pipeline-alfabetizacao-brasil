# Pipeline Híbrido para Análise da Alfabetização no Brasil

## Contexto
Este projeto implementa uma pipeline híbrida de dados (Batch + Streaming) 
para análise do Indicador Criança Alfabetizada, desenvolvido como Tech Challenge 
da Pós-Tech FIAP.

## Arquitetura
- **Bronze Layer**: Dados brutos ingeridos das fontes
- **Silver Layer**: Dados tratados e padronizados
- **Gold Layer**: Dados analíticos prontos para análise

## Stack Tecnológico
- **Cloud**: AWS (S3, Glue, Athena, Kinesis, Lambda, CloudWatch)
- **Linguagem**: Python 3.x
- **Formato**: Parquet (otimizado para custo e performance)
- **Orquestração**: AWS Glue Workflows
